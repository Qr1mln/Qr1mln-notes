# 链表
> 非连续存储的数据结构。
> 数据元素称为节点。
 
特殊节点有：头节点、首节点、尾节点。。
* 头结点：存储链表长度和统一操作，免去第一次操作的判断。
* 首节点：存储链表的第一个元素。
* 尾节点：存储链表的最后一个元素。

## 单向链表

> 元素之间通过一个单向next指针维系下个元素的地址，只能单向查找。

### 操作效率

#### 查询
##### 按值查询
这个值在链表的第几个节点。
效率：O(n)

##### 按位置查询
获取指定位置的节点。
效率：O(n)

#### 插入
思路：先查询到指定位置的上一个节点（i-1），然后插入新节点。
效率：O(1)

#### 删除
思路：先查询到指定位置的上一个节点（i-1），然后更新next为删除节点的next。
效率：O(1)
