# 神技解法
## 消消乐

###  左右法

> 快速确定主键

| 关系依赖左边值 | 关系依赖右边值 |
| -------------- | -------------- |
| A1             | A2             |
| A2             | A3             |
| A3             |                |

左右对消

结果

| 关系依赖左边值 | 关系依赖右边值 |
| -------------- | -------------- |
| A1             |                |
|                |                |
|                |                |

主键必定有A1。
